Forest Cover in the Sumatra and Orangutan Sightings

This project is intended to find a link between orangutans and the loss of habitat in the Sumatra. 
The method is to plot the forest cover of the Sumatra and orangutan sightings to find any patterns.

Instructions for running the example provided in main.py
 - run main.py
 - open figure Aceh_Map.png, N_Sumatra_Map.png, and trends.png to view results

File List 

  -indonesia.geojson
    Contains the geopandas of Indonesia, as well as the borders of Provinces like Aceh and North Sumatra
    
  -Sumatra_processed_forest_data.csv
    Contains forest data of Sumatra, most importantly contains data of the intact forest of Sumatra with years
    
  -Orangutan_Sighting.csv
    Contains data of orangutan sightings with the year it was spotted
    
Findings
There is an inverse relationship between forest cover and orangutan sightings.
